# PrintCraft - PDF Workbench

## About PrintCraft

PrintCraft is an open source PDF workbench built for people who need to merge, split, and reorganize documents without fighting bloated menus. PrintCraft treats every PDF as a set of movable, extractable, and combinable pages, so the PrintCraft PDF workbench stays readable from the first launch. Whether you are assembling a report, pulling a single chapter out of a long scan, or rebuilding a packet for review, PrintCraft PDF editor keeps the process steady and predictable.

The tool exists because most PDF tasks are simple but scattered. You merge in one place, split in another, and rearrange somewhere else. PrintCraft merge PDF and PrintCraft split PDF live in the same workspace, which means fewer detours and fewer mistakes. PrintCraft open source means the logic is visible, the roadmap is public, and the community can shape what comes next.

PrintCraft is not trying to be a full design suite. It is a focused PDF workbench for merging, splitting, extracting, and reordering pages. That narrow scope is the point: one calm environment, clear page thumbnails, and a result you can verify before saving.

## Overview

![PrintCraft](https://getartcraft.com/images/apps/printcraft/hero.webp)

PrintCraft turns a stack of PDFs into a single organized workspace. Open the PrintCraft PDF workbench, load your files, and see every page as a movable unit. PrintCraft PDF editor supports merging multiple documents into one, splitting a large file into smaller parts, and rearranging page order with drag-and-drop simplicity.

The interface stays out of the way. You get a page grid, a file list, and clear actions for merge, split, extract, and reorder. PrintCraft merge PDF works across mixed sources, so you can combine scans, exports, and downloaded documents into one clean result. PrintCraft split PDF lets you cut by page range, by bookmark, or by fixed intervals, depending on what the document needs.

Because PrintCraft is open source, every operation is transparent. You can inspect how pages are handled, contribute fixes, or adapt the workbench to a specific workflow. PrintCraft open source also means no hidden telemetry and no surprise changes to how your files are processed.

## Quick Start with PrintCraft

1. **Open PrintCraft** – Launch the PrintCraft PDF workbench and confirm your workspace layout.
2. **Load files** – Add one or more PDFs to the file list; PrintCraft merge PDF supports mixed sources.
3. **Choose an action** – Select merge, split, extract, or reorder depending on your goal.
4. **Arrange pages** – Drag thumbnails to set the final order before saving.
5. **Save the result** – Export the new PDF to a location you control.
